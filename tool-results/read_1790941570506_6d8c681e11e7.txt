     5→# Chat Completions API
     6→
     7→> Use the OpenAI API compatible Chat Completions format to call MiniMax models.
     8→
     9→<Note>
    10→  ✨ **New model — `MiniMax-M3.1-Flash-Preview`**
    11→
    12→  **Core capabilities**: **1M long context**, **multimodal**, **tunable thinking depth**.
    13→
    14→  Available only through M Plan and MiniMax Code for now.
    15→</Note>
    16→
    17→<Tip>
    18→  **What's new in `MiniMax-M3.1-Flash-Preview`:**
    19→
    20→  1. Image and video understanding — see the example code on the right
    21→  2. Tune thinking depth via `reasoning_effort`, which accepts `low`, `medium`, `high`, `xhigh`, and `max`; the default is `max`
    22→  3. Thinking is on by default with no configuration needed; thinking content is returned separately on the `reasoning_content` field
    23→</Tip>
    24→
